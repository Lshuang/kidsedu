# 幼小衔接乐园 · 多娃学习工作台

> 一款专为 **5–6 岁幼小衔接 / 幼儿园大班** 及 **多子女家庭** 设计的卡通风响应式 Web 学习工作台。
> 零依赖、纯前端、单文件，可安装到手机 / 平板桌面，离线也能用。

---

## ✨ 功能特性

- **多小孩数据隔离**：顶部头像下拉切换（哥哥 / 妹妹…），积分、字库、计划、打卡、复习队列、电视时长、兑换券、勋章墙**全部按小孩独立**，互不影响；支持新增 / 编辑 / 删除小孩。
- **内置幼小衔接知识库**
  - 拼音：声母 23 + 韵母 24 + 整体认读 16，点读发音 + 四声调家族朗读
  - 识字：646 字库（160 高频字带拼音 / 组词 / 图形提示 + 486 扩展字）
  - 古诗词：21 首必背，全注音 + 标准朗读
  - 英语：A–Z 自然拼读 + 6 主题 56 词，标准发音
  - 数学：3–10 分合图解 + 5 / 10 / 20 以内口算测试
  - 科普百科：动物 / 植物 / 太空 / 身体 / 生活科学 5 大主题 26 条趣味小百科，整段语音朗读
  - 经典故事绘本：龟兔赛跑、小马过河、三只小猪等 8 个睡前故事，一键"讲故事"整篇朗读 + 文字指读 + 故事道理
- **智能每日计划**：每孩独立目标（如哥哥每天 5 字、妹妹 2 字）；点「不熟练」自动进次日复习队列。
- **习惯打卡 + 盲盒**：5 项自理能力打卡，随机触发盲盒积分奖励。
- **娱乐 / 电视时长管理**：积分兑换制（20 分 → 15 分钟，比例可调），超时弹出护眼提醒。
- **多元化积分商城**：5 大类 16 项奖励（生活特权 / 家庭陪伴 / 户外体验 / 娱乐时光 / **优选观影**），兑换生成带小孩名字的兑换券；另有打卡盲盒随机奖励。
  - **优选观影**：预置央视推荐 / 有教育意义的动画与纪录片兑换项——《螺丝钉》《土豆逗》《超级宝贝JoJo》《中国唱诗班》《微观小世界》《航拍中国》，把屏幕时间变成有引导的优质内容时间。
- **家长控制中心**：连点 Logo 5 次或 PIN（默认 8888）解锁；小孩管理、学习目标、积分补签核销、商城编辑、避坑指南。
- **语音朗读**：所有拼音 / 汉字 / 古诗 / 英文词均带声音图标（Web Speech API）。
- **正向激励**：打卡 / 答对触发满屏彩带动画 + 清脆鼓励音效。
- **PWA 可安装**：支持「添加到主屏幕 / 安装到桌面」，全屏启动、离线可用。

## 🛠 技术栈

- 纯 **HTML / CSS / JavaScript** 单文件应用（`index.html`），无任何第三方依赖
- **PWA**：`manifest.webmanifest` + `sw.js`（Service Worker 离线缓存）
- **数据持久化**：浏览器 `localStorage`（按浏览器 / 设备隔离）
- **图标**：`icon-192.png` / `icon-512.png`（马卡龙渐变 + 星星）

## 📁 目录结构

```
.
├── index.html            # 主程序（单文件应用，含全部逻辑与数据）
├── manifest.webmanifest  # PWA 清单（名称 / 图标 / 全屏模式）
├── sw.js                 # Service Worker（离线缓存）
├── icon-192.png          # 应用图标（192×192）
├── icon-512.png          # 应用图标（512×512，兼容 maskable）
├── .nojekyll             # 让 GitHub Pages 跳过 Jekyll，直接静态发布
├── .gitignore            # 忽略 .workbuddy/（本地记忆与配置，不入库）
└── README.md
```

## 🚀 本地运行

方式一：直接双击 `index.html` 在浏览器打开即可（`file://` 可用，但「安装到桌面」和离线功能需要 https）。

方式二（推荐，启用 Service Worker）：用本地服务器

```bash
# 在项目目录下
python3 -m http.server 8000
# 浏览器访问 http://localhost:8000
```

## ☁️ 部署到公网（GitHub Pages）

1. 把本目录推送到你的 GitHub **公开** 仓库（代码为纯前端、不含任何密钥，公开安全）
2. 仓库 **Settings → Pages → Source** 选择 `main` 分支、目录 `/(root)`
3. 等待构建完成，访问 `https://<你的用户名>.github.io/<仓库名>/`

> 本项目已部署示例：**https://lshuang.github.io/kidsedu/**
>
> 提示：GitHub Pages 首次构建可能较慢；若卡在 `building`，在仓库根目录放一个空文件 `.nojekyll` 可跳过 Jekyll 直接静态发布。

## 📱 安装到手机 / 平板桌面

需要 **通过 https 访问** 才能「安装」。

- **Android（Chrome / Edge）**：打开站点 → 右上角 ⋮ 菜单 → **「安装应用」**（或「添加到主屏幕」）
- **iPhone / iPad（Safari）**：打开站点 → 底部「分享」按钮 → **「添加到主屏幕」**

装好后点开即全屏，像原生 App；多小孩各自切换，数据互不干扰。

## 👨‍👩‍👧 使用说明

- **切换 / 新增小孩**：点顶部右侧头像按钮，下拉可切换、新增、编辑、删除小孩（名字、称呼、emoji 头像、年级、每日目标）。
- **家长模式**：连续点击顶部 **Logo 5 次**，或输入 PIN（默认 `8888`）。
- **每日目标**：在家长中心为每个小孩独立配置识字量、电视上限、积分兑换比例等。
- **积分获取**：完成计划、打卡、答对题目、抽中盲盒都会加分。
- **兑换奖励**：在商城用积分兑换，生成带小孩名字的兑换券，由家长核销。

## 🔒 隐私说明

- 所有学习数据**仅保存在你本地浏览器**（`localStorage`），**不上传任何服务器**。
- 数据按**设备 / 浏览器**隔离，换手机或换浏览器不会自动同步（如需多设备同步，可后续扩展云同步层）。
- 仓库为公开静态站点，代码中**不含任何密钥或个人隐私信息**。

## 🔄 多设备同步（备份 / 恢复）

数据默认只存在本机浏览器。要在手机、平板之间迁移或备份，使用家长中心的 **「💾 备份同步」** 标签页：

- **导出备份**：把全部小孩数据下载为一个 `.json` 文件（可用微信文件传输助手发到另一台设备）
- **导入备份**：在新设备打开应用后导入该文件，即可恢复全部进度

> 这是隐私优先的「手动云同步」——文件始终在你手里，不上传任何服务器。如需自动实时云端同步，可后续接入 Supabase / Firebase 等服务。

## 🔧 自定义

- **修改知识库内容**：编辑 `index.html` 中对应的数据段（拼音 / 识字 / 古诗 / 英语 / 数学）。
- **修改家长 PIN**：在 `index.html` 中搜索 `8888` 替换为你的密码。
- **调整积分 / 电视比例**：家长中心内即可实时调整，无需改代码。
- **更换图标**：替换 `icon-192.png` / `icon-512.png` 并同步更新 `manifest.webmanifest`。
