# 幼小衔接乐园 · 多娃学习工作台

> 一款专为 **5–6 岁幼小衔接 / 幼儿园大班** 及 **多子女家庭** 设计的卡通风响应式 Web 学习工作台。
> 零依赖、纯前端、单文件，可安装到手机 / 平板桌面，离线也能用。

---

## 📖 项目背景

本项目源于一个真实的多子女家庭需求：大班孩子进入幼小衔接阶段，需要一套**每天少量、正向激励、多娃数据互不干扰**的学习打卡工具，同时把"看电视时间"变成需要用学习积分兑换的资源。整个应用由 AI 编程助手（WorkBuddy）通过多轮对话从零构建并部署上线。

## ✨ 功能特性

- **多小孩数据隔离**：顶部头像下拉切换（哥哥 / 妹妹…），积分、字库、计划、打卡、复习队列、电视时长、兑换券、勋章墙**全部按小孩独立**，互不影响；支持新增 / 编辑 / 删除小孩。
- **内置幼小衔接知识库**
  - 拼音：声母 23 + 韵母 24 + 整体认读 16，点读发音 + 四声调家族朗读
  - 识字：646 字库（160 高频字带拼音 / 组词 / 图形提示 + 486 扩展字）
  - 古诗词：21 首必背，全注音 + 标准朗读
  - 英语：A–Z 自然拼读 + 6 主题 56 词，标准发音；**SSS 经典儿歌 20 首**（点卡片听英文歌名+首句，会唱了点亮 ⭐，+3 分）、**牛津阅读树分级读物 20 本**（点封面打开**绘本阅读器**：每本 5 页原创图文，大图 emoji 场景 + 英文句子 + 中文翻译，点画面听英文发音，亲子共读后点亮 ✅，+3 分）
  - 数学：3–10 分合图解 + 5 / 10 / 20 以内口算测试；**游戏化数学**（数一数 / 比大小 / 认形状 三款小游戏，每答对 +2 分）
  - 科普百科：**10 大知识分类 × 100 条 = 1000 条**趣味小百科（动物 / 昆虫 / 海洋 / 恐龙 / 植物 / 地球天气 / 太空 / 身体 / 生活科学 / 科技交通），整段语音朗读，分页浏览
  - 经典故事绘本：**50 个**睡前经典（童话 / 寓言 / 成语故事），一键"讲故事"整篇朗读 + 文字指读 + 故事道理，分页浏览
- **智能每日计划**：每孩独立目标（如哥哥每天 5 字、妹妹 2 字）；点「不熟练」自动进次日复习队列。
- **习惯打卡 + 盲盒**：5 项自理能力打卡，随机触发盲盒积分奖励。
- **娱乐 / 电视时长管理**：积分兑换制（20 分 → 15 分钟，比例可调），超时弹出护眼提醒。
- **多元化积分商城**：**8 大类 80 项**奖励（生活特权 / 家庭陪伴 / 户外体验 / **优选观影** / 娱乐时光 / 美食甜点 / 学习装备 / 成长惊喜），分类筛选浏览，兑换生成带小孩名字的兑换券；另有打卡盲盒随机奖励。
  - **优选观影**：预置央视推荐 / 有教育意义的动画与纪录片兑换项——《螺丝钉》《土豆逗》《超级宝贝JoJo》《中国唱诗班》《微观小世界》《航拍中国》，把屏幕时间变成有引导的优质内容时间。
- **家长控制中心**：连点 Logo 5 次或 PIN（默认 8888）解锁；小孩管理、学习目标、积分补签核销、商城编辑、避坑指南、**朗读音色设置**（自动优选设备上最接近播音员的音色，Edge 浏览器可用"晓晓/云健"等 Natural 在线音色）。
- **语音朗读**：所有拼音 / 汉字 / 古诗 / 英文词均带声音图标（Web Speech API）。
- **正向激励**：打卡 / 答对触发满屏彩带动画 + 清脆鼓励音效。
- **PWA 可安装**：支持「添加到主屏幕 / 安装到桌面」，全屏启动、离线可用。

## 🛠 技术栈

- 纯 **HTML / CSS / JavaScript** 单文件应用（`index.html`），无任何第三方依赖
- **PWA**：`manifest.webmanifest` + `sw.js`（Service Worker 离线缓存）
- **数据持久化**：浏览器 `localStorage`（按浏览器 / 设备隔离）
- **图标**：`icon-192.png` / `icon-512.png`（马卡龙渐变 + 星星）

## 🚀 本地运行

方式一：直接双击 `index.html` 在浏览器打开即可（`file://` 可用，但「安装到桌面」和离线功能需要 https）。

方式二（推荐，启用 Service Worker）：用本地服务器

```bash
# 在项目目录下
python3 -m http.server 8000
# 浏览器访问 http://localhost:8000
```

## 🔒 隐私说明

- 所有学习数据**仅保存在你本地浏览器**（`localStorage`），**不上传任何服务器**。
- 数据按**设备 / 浏览器**隔离，换手机或换浏览器不会自动同步（如需多设备同步，可后续扩展云同步层）。
- 仓库为公开静态站点，代码中**不含任何密钥或个人隐私信息**。

## 🔄 多设备同步（备份 / 恢复）

数据默认只存在本机浏览器。要在手机、平板之间迁移或备份，使用家长中心的 **「💾 备份同步」** 标签页：

- **导出备份**：把全部小孩数据下载为一个 `.json` 文件（可用微信文件传输助手发到另一台设备）
- **导入备份**：在新设备打开应用后导入该文件，即可恢复全部进度
- **同步码（更方便）**：备份页提供「📋 复制同步码 / 📥 粘贴导入」，把全部进度压缩成一段文本，用微信在手机/电脑间直接粘贴迁移，比传文件更省事

> 这是隐私优先的「手动云同步」——数据始终在你手里，不上传任何服务器。如需自动实时云端同步（多设备改一处、处处更新），可后续接入 Supabase / Firebase / 腾讯云 CloudBase 等后端服务。

## 📱 手机上没声音？排查清单

朗读声音走两条路径：**① 系统语音（Web Speech API）** 和 **② 在线语音（HTML 音频，默认）**。应用默认用**在线语音**，因为它与「按键音」走同一条音频通道，在手机上最稳。绝大多数「点了没声音」都能按下面排查：

1. **先区分：按键音 vs 朗读**。若**按键音有、朗读没有**，说明音频输出正常，问题在语音源（见下）；若连按键音都没有，多半是 iPhone 静音键拨到了静音或音量过低——把静音键拨回响铃、拉起音量即可。
2. **在线语音需要联网**：默认在线朗读依赖网络（有道 / 百度 / 谷歌翻译三个音源自动择优）。完全离线时朗读会没声——可在家长中心把「朗读引擎」切到「📱 设备语音」（前提是设备装了中文 TTS 语音包）。
3. **微信 / 部分 App 内置浏览器限制**：建议用**系统自带浏览器**或 **Chrome / Edge** 打开，兼容性最好。
4. **华为 / 荣耀（鸿蒙）**：系统常缺网页语音包，直接选「🌐 在线语音」即可正常发声。

> 技术要点：朗读在用户**点击的同步手势内**触发（避免被移动端自动播放策略拦截）；设备无可用语音时直接同步走在线，不靠定时器兜底；保留 `SpeechSynthesisUtterance` 全局引用防 GC；`AudioContext` 在 `suspended` 时主动 `resume()`。
